# Documentation Rules

- Keep current product documentation accurate for macOS 15+ on Apple Silicon,
  Tauri 2, Rust, React/TypeScript, shadcn/ui, and Base UI.
- Treat docs/migration/m0* through m5* as historical checkpoints; use
  docs/migration/completion-report.md for the current migration result.
- Keep English and Japanese mirrors aligned when a mirror already exists.
  Do not create new Japanese mirrors unless requested.
- PR titles for docs-only changes should use docs: <description>.
