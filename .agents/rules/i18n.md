# i18n Rules

- The application supports English and Japanese in its React and native Qt UI.
- For React UI, provide both English and Japanese strings with the shared
  `text(locale, english, japanese)` helper and pass the active locale through
  screen props. Keep tool labels and descriptions in the React tool registry.
- For native C++ UI, use Qt's `tr()` translation support. Japanese translations
  for native Qt text are tracked in `res/dev-tools_ja_JP.ts`.
- Normal builds generate `.qm` files but must not update `.ts` files.
- Update `.ts` only when translatable strings change:

```bash
cmake --build build --target update_devtools_translations
```

- Compile translations with:

```bash
cmake --build build --target release_devtools_translations
```
