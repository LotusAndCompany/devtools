# Localization Rules

- The UI supports English and Japanese.
- Use the shared text(locale, english, japanese) helper for localized UI
  text and pass the active locale through component props.
- Keep tool names and descriptions in the React tool registry.
- There is no Qt Linguist catalog or generated .qm translation in the app.
- Check both locales when adding or changing visible strings.
